# Casa Tikkun

Aplicación web de Casa Tikkun, un alojamiento ubicado en Santa Elena, Antioquia.

## Ejecutar en local

**Requisito:** Node.js.

1. Instala las dependencias: `npm install`.
2. Si corresponde, configura las variables públicas del frontend en `.env.local` (por ejemplo, `VITE_AUTH_API_BASE_URL`). No pongas secretos en variables `VITE_*`: Vite las incorpora al código visible en el navegador.
3. Inicia el servidor de desarrollo: `npm run dev`.

La aplicación estará disponible en la dirección local que indique Vite en la terminal.
