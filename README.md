Stack Tecnologico Frontend:
--------------------------------------------------------------------------
React (v19): Biblioteca principal para la construcción de interfaces de usuario.
Vite (v8): Herramienta de compilación y servidor de desarrollo (rápido y moderno).
TypeScript (v7): Lenguaje principal del proyecto, aportando tipado estático a JavaScript.
Tailwind CSS (v4): Framework de utilidades CSS para el diseño y estilizado rápido (usando el plugin de Vite @tailwindcss/vite).
Motion: Probablemente Framer Motion (o similar) para el manejo de animaciones complejas y fluidas en la interfaz.
Lucide React: Biblioteca para incorporar íconos en los componentes de React.
@google/genai: SDK para integración con servicios de Inteligencia Artificial Generativa de Google.
